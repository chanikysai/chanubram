## Prerequisites

- See the tech stack section above for runtime requirements

## Installation

```bash
npm install
```

## Environment Variables

Create a `.env` file in the project root and set the required variables.
Common variables to add:
```
DATABASE_URL=<your database connection string>
NODE_ENV=development
```

## Start the Development Server

```bash
npm run dev
```

The app will be available at **http://localhost:3000** (or the port configured in your `.env`).

## Run Tests

```bash
npm test
```
