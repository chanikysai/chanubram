# Types

This directory defines the TypeScript interfaces and types used throughout the application.

## `product.ts`

Defines the `Product` interface, representing the structure of product data.
Includes properties like `id`, `name`, `description`, `price`, and `imageUrl`.

## `review.ts`

Defines the `Review` interface, representing the structure of a customer review.
Includes properties like `id`, `productId`, `userId`, `rating`, `comment`, and `createdAt`.
